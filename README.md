# Agent Study

个人 Agent 学习项目，基于 Node.js、TypeScript 和 SQLite，部分代码由 Codex 辅助编写。

## 已实现的学习功能

- **Agent 基础**：模型请求、自定义 XML 工具调用、执行结果回填、多轮工具循环。
- **角色封装**：通过 `new Agent()` 创建通用、图书、文件、天气和知识问答助手，按角色分配工具。
- **工具开发**：文件读取、写入、局部修改，以及天气查询。
- **图书业务**：查询、入库、借阅与归还；参数校验、SQLite 事务、库存约束、借阅重试去重和重复归还处理。
- **上下文管理**：最近3轮历史与本轮工具结果组装，完整会话另存 SQLite。
- **长期记忆**：工具保存用户偏好和项目约定，每轮按用户及项目读取，限制条数和注入长度；暂未实现相关性检索。
- **RAG 入门**：本地 Markdown/TXT 加载、切块、关键词检索、原文与行号引用；暂未使用 Embedding 或向量数据库。
- **任务规划**：Plan & Execute，生成步骤并维护执行状态。
- **多助手协作**：将天气查询、文件读取委派给工具和上下文独立的子助手。
- **答案复查**：单次复查，超时或失败后返回带提示的初稿。
- **运行控制**：超时、取消、循环上限、同会话并发保护、工具错误反馈和执行日志。
- **交互与持久化**：网页 SSE、CLI、模型切换、规则路由、助手配置及 SQLite 会话保存。
- **静态演示**：模拟模式与浏览器直连，能力与本地 Node 版不同。
