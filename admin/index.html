CONNECTIONS

模型配置

集中管理你的模型，按任务自由选择。

ⓘ 模型与 API Key 保存在本机 .data/models.json，不修改 .env；密钥不会返回浏览器。
如何连接自己的模型？

Ollama：填写 http://localhost:11434/v1/chat/completions 和本机已安装的模型名称，通常无需 Key。

公共平台：填写支持 Chat Completions 的完整 HTTPS 接口地址、模型名称和 API Key；ChatGPT 网页订阅不是 API Key。当前版本使用 XML 工具协议，不使用原生 tool_calls。

浏览器直连要求接口允许跨域（CORS）。本地网络访问还可能需要浏览器授权；HTTPS 页面访问 HTTP 也可能受限制。连接失败不会自动转为模拟回复。

Ollama 需通过 OLLAMA_ORIGINS 允许本站 Origin，并重启服务。只允许你信任的站点，不需要把 Ollama 暴露到公网。若浏览器限制直连，可下载项目在本机运行原有 Node 模式。

浏览器版文件工具只操作虚拟文件。工具调用结果会发给当前模型；真实天气请求发往 Open-Meteo。
